# 抽奖码批量管理指南

活动详情页「管理抽奖码」进入管理面板：查询（搜索/状态筛选/分页）、导入、覆盖、
批量删除、编辑参与者信息、导出 CSV。

## CSV 格式

每行「抽奖码,姓名,手机,邮箱」，规则：

- 分隔符支持逗号 / 分号 / Tab（自动嗅探），可直接从 Excel 粘贴或上传 `.csv/.txt/.tsv`
  （Excel 的 `.xlsx` 请先另存为 CSV）
- 首行可为表头（首格为 `抽奖码` 或 `code` 时自动跳过）
- 姓名 / 手机 / 邮箱三列均可空；多余列忽略；单次最多 1000 行
- 抽奖码须符合活动配置的码格式（如 8 位纯数字）
- 文件内重复抽奖码按**后出现的一行**处理

## 导入（upsert）与覆盖（replace）

|                   | 导入                                                         | 覆盖                                    |
| ----------------- | ------------------------------------------------------------ | --------------------------------------- |
| 新码              | 创建                                                         | 创建                                    |
| 已存在的码        | 更新参与者信息（**空列保留旧值**，不清除金山表单写入的字段） | 同左（仅已使用码会幸存到这一步）        |
| 未提及的码        | 不动                                                         | **删除**（全部未使用 + 已作废的业务码） |
| 已使用码 / 测试码 | 不动                                                         | 保留                                    |

- 逐行校验：错误行（格式/手机/邮箱不合规）收集进失败清单，**不拦截整批**——
  有效行照常写入，结果视图逐行列出失败原因
- 配额是活动级约束：导入新增将超出 `max_lottery_codes` 时**整批拒绝**（无半写）
- 覆盖弹窗会先显示「将删除 N 个」并要求确认；**纯清空**可用「覆盖 + 仅一行坏行」实现

## 删除与级联警示

删除已使用的抽奖码时，其关联的**抽奖记录（含签字图片）会被一并级联删除**——
确认弹窗会明确列出将删除的码数、其中已使用数量与受影响记录数。测试码不可删除。

## API 摘要

| 端点                                                               | 说明                                                            |
| ------------------------------------------------------------------ | --------------------------------------------------------------- |
| `POST /admin/activities/:id/lottery-codes/import`                  | `{codes, mode: 'upsert'\|'replace'}`，返回逐行结果与统计        |
| `POST /admin/activities/:id/lottery-codes/batch-delete`            | `{ids}`，逐 id 结果 + summary（used_deleted / records_deleted） |
| `PUT /admin/activities/:id/lottery-codes/:codeId/participant-info` | 更新参与者信息                                                  |
| `GET /admin/activities/:id/lottery-codes`                          | 分页/搜索/状态（unused/used/invalid）筛选，行含 `record_count`  |
| `GET /admin/activities/:id/lottery-codes/export`                   | UTF-8 BOM CSV，与导入格式互逆                                   |
